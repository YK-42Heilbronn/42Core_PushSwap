# 42_Heilbronn - push-swap Project

*This project has been created as part of the 42 curriculum by ykonka*.

## Description

* The goal of this project is to implement the `push_swap` program which sort the shuffled integer stack using radix sort algorithm
* Implementation done in `C` program

* For this, we were authorized to use the following functions:

	- `read`, `write`,
	- `malloc`, `free`
	- `exit`


## Instructions

### Compilation

To get started with this project, follow these steps:
```bash
$ make
```

### Execution

```bash
$ ./push_swap "1 5 -4"
```

### Example

Here’s an example of how to use the push_swap function in Bash Shell:

```bash
#  push_swap sign operators commands
$ ./push_swap " -1 - 5 + 6"
#  push_swap duplicates
$ ./push_swap "2 2"
#  push_swap multi string input
$ ./push_swap "1" "2 9 " "     -3  8"
```
